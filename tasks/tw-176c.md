Build **Favo** (after Favo! by flow Inc.) as a new top-level game in `client-games`, slug `favo`, beside Woodoku and Hex Block. **Keep Hex Block.** The human wants to compare the two. Give it its own OpenSpec spec under `openspec/specs/games-favo/`.

In short:
- a hex board (R = 3 by default)
- 3 mixed-colour panels of 1–3 hexes in a tray; drag one up to place it, tap one in the tray to rotate it
- a connected same-element group of 3 or more clears and fills that element's gauge
- clearing 2 colours in one move scores ×2, all 3 colours ×4
- a full gauge gives a merge panel
- game over when the board is full

Reuse Hex Block's hex math and the drag pattern. Put the rules in pure, tested modules. Check: `npx vitest run client-games && npm run build:games`. Record any rule you chose on this thread.
