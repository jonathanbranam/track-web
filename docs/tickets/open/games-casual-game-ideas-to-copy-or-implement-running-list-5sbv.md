- **"Flow games"** (an arrow tap-away puzzle). The human clarified on 2026-10-04 (verbatim):

  > Flow games have arrows that curve around and point in different directions and you tap the one that points to the exit and it "flows" away. The puzzle is to do them in order

  So it's not flow Inc. and not Flow Free. It's the tap-away arrow genre: a board of curving arrows, each pointing a different way. Tapping an arrow whose path to the exit is clear makes it flow off the board. Arrows that are blocked have to wait, so the puzzle is finding the order that clears the board.
