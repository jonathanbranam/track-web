### note · agent:hexpuzzle · 2026-10-01T22:48:19.127Z
Built Hex Block (client-games/src/games/hex-block/, slug hex-block, registry entry, spec openspec/specs/games-hex-block). Ticket doc was present in the worktree. Check green (313 tests, build:games).
Rules chosen (Update 4): R=4, 61 cells, 27 lines. 1-4 hex pieces from base shapes (single, line 2/3/4, triangle, bent three, rhombus, arc, zigzag) expanded to all distinct rotations/mirrors as fixed orientations; weights 3/3/2/1 by size; each hex random red/blue/green with bird/note/leaf outline. 3-piece tray, refill when empty, game over when none fits. Score: +1 per hex placed; with clears (2*distinct cleared cells + 4*sum of one-colour line lengths) * 2^(lines-1), i.e. a one-colour line counts x3 without double-counting shared cells. Counters = cleared hexes per colour. Best in localStorage (hex-block.best).
Reuse: copied Woodoku's pattern (pointer-capture drag from tray, lift, spring-back, best storage, game-over overlay) rather than importing, since its grid types differ; kept SVG + React, no Phaser.
Left out: streak multiplier (ticket's earlier proposal, not in Update 4), clear animation (clear cells are only pre-highlighted before the drop, as in Woodoku), hold slot, rotation, no component/browser test (pure modules tested: hex math, pieces, placement, clears, scoring, snapping). Not driven in a browser.
