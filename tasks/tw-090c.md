From the human, 2026-09-28, via advisor (verbatim). Game: client-games space-golf (`client-games/src/games/space-golf/`, spec `openspec/specs/games-space-golf/spec.md`).

> the nudge power maximum should be directional: when nudging left/right/forwards (from the current movement vector) keep the existing max level; but for the nudge component of the vector that is in the opposite direction of the current velocity, allow a different max level for the nudge; The concept is that the ship has special rockets that it can use to slow down; this will help make it easier to not overshoot; the max nudge velocity for backwards should be adjustable in settings separate from the other vectors
